# Practice Boss start live acceptance

Use a matching current planner and installed game-module build. For each
check, author a valid plan through the biome's Boss, choose that biome's
**Boss** under Route › Practice mode, send it, and start a run. Source probes
and automated tests are not live verification; the owner confirms or waives
each remaining check.

At every Boss start, observe:

- the run opens in the Boss room with the boss's own music and entrance, with
  no shop and no Preboss story replayed;
- execution stays synchronized past the start-room self-check (maxima and
  biome depth);
- with Tight Deadline active, the timer starts with the vow's full allowance;
- clearing the Boss leads to the planned Postboss (or the run's end), whose
  Well or shops appear as in a full run.
