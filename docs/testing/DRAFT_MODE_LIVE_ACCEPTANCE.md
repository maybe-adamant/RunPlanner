# Draft Mode live acceptance

Use a matching current planner and installed game module. On the Route tab's
Draft panel, pick four gods, a story NPC and field NPCs per biome, a few basket
traits and one rack keepsake, then press **Draft**. Publish the drafted project
and start the run it describes.

## Drafted plan in game

- [ ] The run follows the drafted plan from the first room to the end with the
      status window Synchronized: doors, rewards, trait offers and selections
      match, with no conformance mismatch.
- [ ] Each drafted story NPC's room appears where the plan places it, and each
      drafted field NPC appears in its planned encounter.
- [ ] Every combat encounter matches the plan: wave count, enemy types and
      counts, Fangs perks and Menace replacements are as planned.
- [ ] Each basket trait the report marks met is offered and taken where the
      plan places it, including any follow-up choice (a Circe resolution,
      Bridal Glow's target, All Together's results).
- [ ] The drafted rack keepsake is equipped at its Postboss rack.

## Basket and pool order

- [ ] With gods clicked into a pool order, the run's first Olympian boon is
      pool #1's and each new god arrives in pool order.
- [ ] A god's basket traits are taken in the basket's order for that god; a
      Duo is taken in a god room of either of its gods once its prerequisites
      are held.
- [ ] With **Plan up to** set below the full route, the drafted plan, racks and
      report stop at the last planned biome and the run plays synchronized to
      that point.

## NPC windows and purchases

- [ ] A selected field NPC whose window opens in its biome is met in a room the
      plan places inside that window, with a door reward its encounter accepts;
      a missed window shows as unmet in the report.
- [ ] Shop purchases in the plan are offered and bought in game: a god's boon
      or Mystery boon feeding its next basket trait, Hermes or a Hammer when
      the basket needs one.
- [ ] With **Prefer midshops** on, each planned biome's midshop is entered when
      the plan reaches one.

## Fresh File

Create a Fresh File route, open the Draft panel and pick a pool with Apollo
locked as #1 and Poseidon or Demeter included, a few basket traits and
**Prefer midshops**, then **Draft**, publish and start the run.

- [ ] The basket dialog shows no Bonus or NPC tab, the panel has no NPC rows,
      and the loadout drafts as the route's fixed one.
- [ ] The run's first boon is Apollo's from the first-run offer (Attack, Sprint
      or Magick) and plays synchronized to the end of the plan.
- [ ] Where a door offers a god not yet met whose basket traits are queued, the
      plan takes it over a Shop door, and every Shop the plan enters stocks only
      gods already met.

## Reroll

- [ ] **Reroll** drafts a different plan under a new seed; **Draft** again at
      that seed gives the same plan, and it also plays synchronized.
