Run Planner — Windows portable preview

Run RunPlanner.exe directly. No installation is required.

Requirements:
- 64-bit Windows 10 or Windows 11
- Microsoft Edge WebView2 Runtime (included with supported Windows releases)

Project profiles saved as .runplanner.json files are portable and can be moved
between machines. Autosave recovery is machine-local WebView data and does not
travel with this folder.

This preview is not code signed, so Windows may show an unrecognized-app
warning for a freshly downloaded release.
